Sonnet with no skill and told not to use any skill.

Changes made after run 1:
- Chat answers open with the whole path in brief and must carry five facts: repo root,
  README with install and licence, browser sign-in, private first, release .zip.
- Bundled scripts: run by full path in Claude Code; one-line `curl` download in chat (several
  answers had told the developer to run `scripts/...` they don't have).
- Scrub step ends with `git init` and `git status --short --untracked-files=all`; private files
  move out of the skill folder, not just into `.gitignore`.
- Committed-secret section: delete releases built from a commit that held the secret.

## Description tuning

Judged by name and description alone against the eval near-misses and these should-trigger
prompts: "put my skill on GitHub", "share my FileMaker skill with other devs", "make my skill
installable with claude plugin install", "my skill zip won't upload to Claude", "release
v1.2 of my skill", "set up a plugin marketplace for my skills", "I committed a password to my
skill repo". Added "set up their own plugin marketplace" after the marketplace prompt matched
only weakly. Near-misses stay out through the "Not for" clause (skill building, CadenceUX
releases, hook plugins, Git for a FileMaker solution); "push my web viewer app" doesn't match
because every trigger names a skill.

## Tooling checks (same day)

- `scripts/scan_for_client_material.sh` on a seeded fixture: reported the .fmp12, .env,
  `fmnet:` address, Re-Login password, IP and client email, and the old password in history;
  allowed the GitHub noreply address; clean folder exits 0; bad path exits 2.
- `scripts/build_release.sh`: missing tag, version mismatch (three files named) and manifest
  leak all fail with a specific message and leave earlier archives untouched; a good build
  excludes `evals/`, `.claude-plugin/` and uncommitted files, and the .skill copy is identical.
- Single-repo marketplace (`"source": "./"`, `"skills": ["./"]`) installed with
  `claude plugin marketplace add` / `claude plugin install` and passed `claude plugin validate`.
